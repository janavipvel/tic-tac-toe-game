Tic Tac Toe — 100 Levels Edition

A classic, dark-themed Tic Tac Toe web application built with Python (Flask), HTML, CSS, and JavaScript. Play across 100 progressively harder levels, track your speed with a live game timer, and earn coins based on how fast you win.

Features:

100 Scaling Levels: Difficulty increases gradually from Level 1 (easy/random moves) up to Level 100 (unbeatable AI).

Level Tracker: Interactive level selector grid displaying unplayed levels in dark purple and cleared levels in dark green.

Live Timer & Pause Control: Built-in match timer that pauses immediately when you click Pause and resets when you exit.

Speed-Based Coin Rewards: Earn bonus coins the faster you beat each level, saved automatically in your browser.

Classic Dark Theme: Styled in navy blue, dark green, maroon, dark purple, and topaz yellow.

Tech Stack:

Backend: Python 3, Flask

Frontend: HTML5, CSS3, Vanilla JavaScript

Hosting: Vercel
